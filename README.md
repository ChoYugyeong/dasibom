# 다시봄 🌱

저장하고, 다시 보는 습관 — 링크 북마크를 출처별·컬렉션별로 모아두고 잊기 전에 다시 꺼내 보는 앱.

인스타그램·유튜브·틱톡 등에서 저장만 해두고 다시 안 보는 링크들을, 도메인으로 자동 분류하고 "오늘의 다시봄"으로 다시 상기시켜 줍니다.

**두 가지 방식으로 쓸 수 있어요:**
- 🖥️ **데스크톱 앱 (Electron)** — 옵시디언처럼 내가 지정한 폴더의 `bookmarks.json` 파일에 자동 저장. 그 폴더를 git으로 공유·백업.
- 🌐 **웹** — 브라우저 `localStorage`에 저장. 서버 없이 어디서나. → https://choyugyeong.github.io/dasibom/

## 주요 기능

- **링크 붙여넣기 저장** — 도메인으로 출처(인스타/유튜브/네이버 등) 자동 감지
- **제목·썸네일 자동 가져오기** (데스크톱 앱) — 링크를 붙여넣으면 실제 페이지의 제목·썸네일을 자동으로 채웁니다. 유튜브·틱톡은 공식 oEmbed, 트위터/X는 oEmbed, 그 외는 OpenGraph 태그를 사용하며 **로그인·API 키가 필요 없습니다** (공개 게시물 한정)
- **다시 보기 유도** — 오래 안 본 북마크를 히어로 영역에 무작위로 노출
- **컬렉션** — 이모지·컬러로 나만의 폴더 구성
- **검색 / 출처 필터 / 잊혀진 북마크 모아보기**
- **선택 모드** — 여러 개 한 번에 봄 처리·이동·삭제
- **백업** — JSON 내보내기 / 가져오기
- **외부 내보내기 대량 가져오기** (데스크톱 앱) — Google Takeout(유튜브)·인스타그램 "내 정보 다운로드" 파일을 한 번에 가져옵니다
- **유튜브 연동** (데스크톱 앱) — Google 계정으로 로그인해 좋아요 표시한 동영상·재생목록을 가져옵니다 (본인의 Google Cloud OAuth 클라이언트 필요)
- **정렬 / 링크 복사** — 최신순·오래된순·제목순 정렬, 카드에서 바로 링크 복사
- **다크모드** — 우측 상단 토글로 전환 (시스템 설정도 자동 반영), 선택은 기기에 저장됩니다
- **접근성** — 키보드로 전체 조작 가능(Tab/Enter/Esc), 스크린리더용 라벨, WCAG AA 대비 기준 준수, `prefers-reduced-motion` 지원

## 데스크톱 앱으로 실행

```bash
npm install       # 최초 1회 (Electron 내려받기)
npm start
```

앱 우측 상단 **📁 저장 위치** 버튼으로 북마크를 저장할 폴더를 지정하세요. 그 폴더에 `bookmarks.json`이 생기고, 추가·수정·삭제할 때마다 자동 저장됩니다. **📂 파일 열기**로 그 파일을 탐색기에서 바로 열 수 있어요.

### 설치 파일(.exe) 만들기

매번 `npm start` 하지 않고 일반 프로그램처럼 쓰려면 Windows 설치 파일을 빌드하세요:

```bash
npm run dist
```

`dist/Dasibom-Setup-1.0.0.exe` (약 78MB)가 생깁니다. 실행해 설치하면 시작 메뉴·바탕화면에 **다시봄** 바로가기가 만들어집니다.

> 처음 빌드 때 `winCodeSign` 압축 해제가 macOS용 심볼릭 링크 때문에 실패하면(코드 서명 안 하면 불필요한 파일), Windows **개발자 모드**를 켜거나 관리자 권한으로 빌드하면 해결됩니다. 코드 서명을 안 하므로 설치 시 SmartScreen 경고가 뜰 수 있는데 "추가 정보 → 실행"으로 진행하면 됩니다.

### 대량 가져오기 (Google Takeout · 인스타그램)

인스타그램은 계정 로그인으로 저장/좋아요 목록을 자동으로 긁어오는 게 불가능합니다(공식 API가 개인 저장 목록 접근을 막아둠). 대신 각 서비스가 공식 제공하는 **내 데이터 다운로드** 기능으로 받은 파일을 이 앱이 읽어 대량으로 가져옵니다. 로그인·API 키가 필요 없고 약관에 위배되지 않습니다.

1. **인스타그램**: 설정 → 계정 센터 → 내 정보 및 권한 → 정보 다운로드 → 형식을 **JSON**으로 선택 → 다운로드 요청 (이메일로 링크가 옵니다). 받은 zip에서 `saved_posts.json`(저장한 게시물) 또는 `liked_posts.json`(좋아요한 게시물)을 꺼내세요.
2. **유튜브**: [Google Takeout](https://takeout.google.com) → **YouTube 및 YouTube Music**만 선택 → "모든 YouTube 데이터 포함" 대신 **재생목록**만 선택 (용량 절약) → 내보내기. 받은 zip의 `Playlists/좋아요 표시한 동영상-videos.csv` 또는 `구독-subscriptions.csv`를 꺼내세요.
3. 다시봄 앱에서 **📥 외부 가져오기** 버튼으로 위 파일(들)을 선택하세요. 여러 개를 한 번에 골라도 됩니다. URL 기준으로 중복은 자동으로 걸러집니다.

### 유튜브 연동 (좋아요 · 재생목록 실시간 가져오기)

Google 계정으로 로그인해 **좋아요 표시한 동영상**과 **재생목록**을 API로 직접 가져옵니다. 유튜브는 공식 데이터 API가 이걸 허용하는 몇 안 되는 서비스라 가능합니다. 다만 **본인 소유의 Google Cloud OAuth 클라이언트**가 있어야 합니다(무료, 5분 정도 소요). 앱 제작자가 미리 발급해둔 공용 키를 쓰지 않는 이유는, 그런 키를 앱에 내장하면 유출 위험이 커지기 때문입니다.

**① Google Cloud 프로젝트 만들기**
1. [Google Cloud Console](https://console.cloud.google.com/)에서 새 프로젝트를 만드세요 (이름 예: `dasibom`).
2. **API 및 서비스 → 라이브러리**에서 **YouTube Data API v3**를 검색해 **사용 설정**하세요.

**② OAuth 동의 화면 설정**
1. **API 및 서비스 → OAuth 동의 화면** → User Type: **외부(External)** 선택 → 앱 이름(`다시봄`), 본인 이메일만 입력하고 저장.
2. **테스트 사용자**에 본인의 Google 계정 이메일을 추가하세요 (게시 심사 없이 바로 쓸 수 있는 방법입니다. 테스트 사용자가 아니면 로그인이 거부됩니다).

**③ OAuth 클라이언트 만들기**
1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**.
2. 애플리케이션 유형: **데스크톱 앱** 선택 → 이름 아무거나 → 만들기.
3. 발급된 **클라이언트 ID**와 **클라이언트 보안 비밀**을 복사해 두세요.

**④ 앱에서 연결**
1. 다시봄 앱 우측 상단 **▶️ 유튜브 연동** 클릭.
2. 위에서 복사한 Client ID / Client Secret을 붙여넣고 저장.
3. 기본 브라우저가 열리며 Google 로그인 창이 뜹니다. 로그인하면 자동으로 앱으로 돌아옵니다.
4. 연결되면 **❤️ 좋아요 표시한 동영상 가져오기** 또는 **🗂️ 재생목록에서 가져오기**로 원하는 만큼 가져오세요.

> 로그인 정보(refresh token)는 Windows 자격증명 저장소(DPAPI)로 암호화되어 로컬에만 저장됩니다. **연결 해제** 버튼으로 언제든 끊을 수 있고, Google 계정의 [보안 → 타사 액세스](https://myaccount.google.com/permissions)에서도 권한을 회수할 수 있습니다.

### 옵시디언식 공유 · 동기화

저장 폴더를 그 자체로 git 저장소로 만들면, 여러 기기에서 데이터를 공유·백업할 수 있습니다:

```bash
cd <저장 폴더> && git init && git add bookmarks.json && git commit -m "backup"
# 다른 기기에서는 pull 후, 앱에서 그 폴더를 '저장 위치'로 지정
```

> ⚠️ 개인 북마크가 담기므로 **비공개(private) 저장소**를 권장합니다. (이 코드 저장소는 공개이고, 데이터 파일 `bookmarks.json`은 `.gitignore`로 제외되어 있습니다.)

## 웹으로 실행 (로컬)

ES 모듈을 쓰므로 `file://`로 직접 열면 동작하지 않습니다. 정적 서버로 여세요:

```bash
python -m http.server 8000
# → http://localhost:8000
```

## 구조

```
index.html          # 마크업 (데스크톱·웹 공용)
css/style.css       # 스타일
js/
├── app.js          # 진입점 — 이벤트 위임 + 초기화
├── constants.js    # 출처 정의, 팔레트
├── utils.js        # 공통 유틸
├── store.js        # 저장소 — 데스크톱은 파일, 웹은 localStorage (이중 모드)
├── view.js         # 렌더링 + 화면 상태
├── actions.js      # 데이터 변경 동작
├── importers.js    # Google Takeout · 인스타그램 내보내기 파일 파서
├── modals.js       # 모달 UI (컬렉션·편집)
├── youtubeModal.js # 유튜브 연동 모달 UI
└── toast.js        # 토스트 알림
electron/
├── main.js         # Electron 메인 — app:// 정적 서빙 + 파일 저장·메타데이터·유튜브 IPC
├── preload.js      # window.dasibom 브리지 (파일·메타데이터·유튜브 API 노출)
├── metadata.js      # 링크 제목·썸네일 가져오기 (oEmbed / OpenGraph)
├── tokenStore.js    # 유튜브 OAuth 자격증명·토큰 암호화 저장
├── youtube-auth.js  # 유튜브 OAuth (PKCE, 루프백 리다이렉트)
└── youtube.js        # YouTube Data API 호출 + 데이터 변환
```

## 데이터에 대하여

- **데스크톱**: 지정한 폴더의 `bookmarks.json` 파일 (미지정 시 앱 데이터 폴더).
- **웹**: 브라우저 `localStorage` (기기·도메인마다 분리).

두 방식 간, 혹은 다른 기기로 옮길 때는 **내보내기 → 가져오기**로 이전할 수 있습니다.
