# 다시봄 🌱

저장하고, 다시 보는 습관 — 링크 북마크를 출처별·컬렉션별로 모아두고 잊기 전에 다시 꺼내 보는 웹앱.

인스타그램·유튜브·틱톡 등에서 저장만 해두고 다시 안 보는 링크들을, 도메인으로 자동 분류하고 "오늘의 다시봄"으로 다시 상기시켜 줍니다. 서버 없이 브라우저 `localStorage`에만 데이터를 저장합니다.

## 주요 기능

- **링크 붙여넣기 저장** — 도메인으로 출처(인스타/유튜브/네이버 등) 자동 감지
- **다시 보기 유도** — 오래 안 본 북마크를 히어로 영역에 무작위로 노출
- **컬렉션** — 이모지·컬러로 나만의 폴더 구성
- **검색 / 출처 필터 / 잊혀진 북마크 모아보기**
- **선택 모드** — 여러 개 한 번에 봄 처리·이동·삭제
- **백업** — JSON 내보내기 / 가져오기

## 구조

```
index.html          # 마크업
css/style.css       # 스타일
js/
├── app.js          # 진입점 — 이벤트 위임 + 초기화
├── constants.js    # 출처 정의, 팔레트
├── utils.js        # 공통 유틸
├── store.js        # localStorage 저장소 + 마이그레이션
├── view.js         # 렌더링 + 화면 상태
├── actions.js      # 데이터 변경 동작
└── modals.js       # 모달 UI
```

## 로컬에서 실행

ES 모듈을 쓰므로 `file://`로 직접 열면 동작하지 않습니다. 정적 서버로 여세요:

```bash
python -m http.server 8000
# → http://localhost:8000
```

## 데이터에 대하여

모든 데이터는 브라우저 `localStorage`에 저장되며 기기·도메인마다 분리됩니다. 다른 주소나 기기로 옮길 때는 **내보내기 → 가져오기**로 이전하세요.
